## 5. IA / Claude para crear webs [UHV]
- Qué hace: skill propia (descarga gratis desde enlace) que, en Claude Code de escritorio, crea una web y la publica en Hostinger; imágenes de stock o generadas con la API de OpenAI; chatbot con API de Google; subida de factura para calcular ahorro, con captura de email.
- Para qué lo usa: **vender páginas web a empresas** (instaladores solares), con llamadas en frío y listados scrapeados. Es un negocio de agencia, no una tienda.
- Calidad: "no es perfecta, es la primera versión". Con un cambio grande aparecen errores [8CE][UHV].
- Utilidad para nosotros **[ESTIMACIÓN]**: baja. Hosting aparte de Shopify, necesita claves de API y código a mantener. Sirve solo como idea de herramienta interactiva (calculadora, chatbot de dudas) o de landing de captación. Para la tienda, su camino dentro de Shopify es Sidekick [onK].
- [8CE] usa un constructor de IA de pago (créditos) con base de datos y páginas generadas desde datos; modelo de afiliados Amazon, no aplicable.

## 6. Productos digitales [VyG] (Alex, no Adrián)
- Definición: archivos PNG/PDF/MP4; ventajas: stock infinito, sin envíos, entrega inmediata.
- **Eligió Etsy, no Shopify**: marketplace "captura demanda"; fuera "persigues atención" con orgánico o anuncios. Adrián lo anuncia como "ventas sin publicidad".
- Propuesta = nicho + producto + estilo; no copiar tendencias; no subir "un producto al día" (mito); calidad primero.
- Validación: IRank, volumen mensual x100 = techo de competencia; etiquetas con Erank.
- **Entrega que enseña**: el cliente recibe un PDF de agradecimiento con botón a un enlace de plantilla de Canva. Descripción con aviso "producto digital, sin devoluciones".
- SEO Etsy: título de cola larga con separadores, 13 etiquetas, no generar título/etiquetas con IA, sí la descripción con contexto y referencia; renovación automática (tarifa de 0,20 $ por venta).
- Algoritmo Etsy: interacción, conversión (CTR), autoridad, SEO. Etsy Ads con poco gasto; tráfico externo de TikTok y Pinterest.
- Entrega con Shopify, descargas, correos, antifraude: **no se cubre**.
